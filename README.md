# Лабораторная работа № 1: основы C++

**Вариант 10. Семейство B — C-строки**

Консольная программа хранит строку в динамической памяти, выполняет базовые операции,
подсчитывает слова и ищет первое вхождение подстроки.
Используются C++20, указатели, ссылки и ручное управление памятью через `new[]` и `delete[]`.
`std::string`, стандартные контейнеры и умные указатели не используются в коде программы.

## Задание варианта

- `str_count_words` считает слова по переходам от пробела к непробельному символу.
  Разделитель — обычный пробел `' '`. Повторные пробелы не создают дополнительных слов.
- `str_find_substr` выполняет наивный поиск: перебирает позиции в строке и сравнивает символы
  подстроки с символами, начиная с каждой позиции. Возвращает признак успеха, а найденную позицию
  записывает по ссылке в `out_pos`.

Пример для строки `hello world test`:

```text
Количество слов: 3
Подстрока world: найдена, позиция 6
Подстрока xyz: не найдена
```

Поиск чувствителен к регистру. Индексы начинаются с нуля.
Длина и позиции считаются в байтах: для текста в UTF-8 они могут отличаться от количества букв.

## Объявленные функции

| Объявление | Назначение |
| --- | --- |
| `std::size_t str_len(const char* s)` | Длина строки до `\0`, без учёта завершающего символа. Для `nullptr` возвращает `0`. |
| `void str_copy(char* dst, const char* src)` | Копирование в готовый буфер вместе с `\0`. При нулевом указателе ничего не меняет. |
| `char* str_alloc(const char* src)` | Создание независимой динамической копии. Для `nullptr` возвращает `nullptr`. |
| `void str_delete(char*& s)` | Освобождение массива и обнуление указателя. Повторное удаление обнулённого указателя безопасно. |
| `void str_print(const char* s)` | Печать строки без добавления перевода строки. Для `nullptr` ничего не выводит. |
| `std::size_t str_count_words(const char* s)` | Подсчёт слов. Для пустой строки и `nullptr` возвращает `0`. |
| `bool str_find_substr(const char* s, const char* sub, int& out_pos)` | Поиск первого вхождения. При успехе возвращает `true` и записывает позицию в `out_pos`. |

Условия использования:

- Ненулевые входные указатели должны указывать на действительные C-строки с завершающим `\0`.
- Для `str_copy` буфер `dst` должен вмещать не менее `str_len(src) + 1` символов;
  области источника и назначения не должны перекрываться.
- Массив, возвращённый `str_alloc`, принадлежит вызывающему коду и освобождается через `str_delete`.
- В `str_delete` передаётся `nullptr` либо указатель на принадлежащий вызывающему коду массив `new[]`.
- При неуспешном поиске `out_pos` не изменяется. Если один из указателей поиска равен `nullptr`,
  функция возвращает `false`.
- Пустая подстрока находится на позиции `0` в любой ненулевой строке, включая пустую.
- Индекс найденной подстроки должен помещаться в `int`. Лимит ввода программы обеспечивает это условие.

## Меню программы

```text
1. Ввести строку
2. Напечатать строку
3. Показать длину
4. Создать копию и напечатать
5. Подсчитать слова и найти подстроку
0. Выход
```

В пункте 5 программа сначала показывает число слов, затем запрашивает подстроку для поиска.
Перед пунктами 2–5 нужно ввести строку. Пустая введённая строка допустима.

Ввод выполняется через временный буфер: максимум **1024 байта текста** и один байт под `\0`.
При успешном вводе новая строка копируется в динамический массив нужного размера, а старая удаляется.
Если строка слишком длинная, программа сообщает об ошибке и возвращается в меню; старая строка сохраняется.
Неверный пункт меню и лишние символы после числа отклоняются.
При выходе или конце ввода текущая строка освобождается. Ошибка выделения памяти также обрабатывается.

## Сборка и запуск

Требуются GNU GCC с поддержкой AddressSanitizer и CMake версии 3.20 или новее.
На Windows команды выполняются в Ubuntu WSL из папки проекта.
Если Google Test отсутствует в системе, CMake скачивает версию `v1.15.2`; для этого нужен интернет.

Первоначальная настройка:

```bash
cmake -S . -B build/debug -DCMAKE_BUILD_TYPE=Debug
```

Сборка и запуск:

```bash
cmake --build build/debug && ./build/debug/lab01_main
```

Запуск тестов:

```bash
ctest --test-dir build/debug --output-on-failure --no-tests=error
```

CMake собирает общую библиотеку `lab01_lib`, программу `lab01_main` и тестовый исполняемый файл `tests`.
Программа и тесты используют одну библиотеку; `main.cpp` не входит в тестовую цель.
AddressSanitizer включён при компиляции и линковке во всех конфигурациях, включая Release.

## Тестирование и оформление

В проекте **15 тестов Google Test**. Проверяются длина, копирование, выделение и освобождение памяти,
подсчёт слов, поиск подстроки, пустые строки и нулевые указатели.
Также проверяются независимость динамической копии и сохранение выходной позиции при неуспешном поиске.

Обычные проверки объединены в набор `StrOpsTest`, ожидаемые отказы — в `StrOpsTest_Fail`.
Оба набора должны проходить: суффикс `_Fail` обозначает проверку ожидаемого отказа функции.
CTest запускает тесты с проверкой утечек памяти через ASan.

Форматирование задаётся предоставленным `.clang-format`: отступ 4 пробела, длина строки до 120 символов.
